Thank you for installing {{ .Chart.Name }}!

Your Squid proxy has been deployed successfully.

1. Get the application URL by running these commands:
{{- if eq .Values.service.type "NodePort" }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "squid-proxy.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo "Squid proxy is available at http://$NODE_IP:$NODE_PORT"
{{- else if eq .Values.service.type "LoadBalancer" }}
  NOTE: It may take a few minutes for the LoadBalancer IP to be available.
        You can watch the status by running 'kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "squid-proxy.fullname" . }}'
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "squid-proxy.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo "Squid proxy is available at http://$SERVICE_IP:{{ .Values.service.port }}"
{{- else if eq .Values.service.type "ClusterIP" }}
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "squid-proxy.name" . }},app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath="{.items[0].metadata.name}")
  echo "Squid proxy is available at http://127.0.0.1:3128"
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 3128:3128
{{- end }}

2. To configure your proxy client, use:
   - Proxy host: {{ include "squid-proxy.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local
   - Proxy port: {{ .Values.service.port }}

3. To view the logs:
   kubectl logs -f deployment/{{ include "squid-proxy.fullname" . }} -n {{ .Release.Namespace }}

4. To customize the Squid configuration, edit the 'squidConfig' section in your values.yaml file
   and upgrade the release:
   helm upgrade {{ .Release.Name }} squid-proxy -f custom-values.yaml

For more information, visit: https://github.com/johan91/squid-k8s
